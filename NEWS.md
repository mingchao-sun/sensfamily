# sensfamily 0.1.0

First version. Two analyses in the menu group Sens:

* **Omitted Variable Bias**: robustness values, partial R2, benchmark bounds with adjusted estimates and confidence intervals, contour plot (Cinelli and Hazlett, 2020).
* **Coefficient Stability**: delta for a target coefficient, bias-adjusted coefficient, bounds and a table over Rmax (Oster, 2019).

Results equal `sensemakr` and `robomit`. Method notes and a data and setup guide are in the Output section of each analysis.
